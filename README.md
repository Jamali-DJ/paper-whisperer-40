# 📄 Paper Pal AI

Paper Pal AI is an AI-powered web application that helps students, researchers, and professionals understand research papers in seconds.

Users can upload PDF research papers and instantly receive:

- 📝 AI-generated summaries
- ❓ Multiple Choice Questions (MCQs)
- 📚 Flashcards
- 🧠 Key concepts
- 📖 Important definitions
- 🎯 Quiz mode for self-testing

---

## 🚀 Features

- Upload PDF research papers
- AI-generated summaries
- Generate high-quality MCQs
- Interactive flashcards
- Quiz mode
- Search uploaded papers
- Modern responsive UI
- Secure authentication
- Cloud storage using Supabase

# 🤖 AI Feature

Paper Pal AI uses OpenAI to analyze uploaded research papers and generate study materials automatically.

The AI can:

- Generate concise summaries
- Create Multiple Choice Questions (MCQs)
- Extract key concepts
- Produce flashcards
- Identify important definitions
- Generate quizzes for self-assessment

### AI Instructions (System Prompt)

The AI is instructed to act as an academic study assistant that carefully analyzes uploaded research papers and generates accurate summaries, quizzes, flashcards, definitions, and key concepts strictly from the paper's content without inventing information.
